# Typhoon Replay Dashboard

An interactive GitHub Pages dashboard for replaying Taiwan-impacting typhoon events with track, wind, rain, station ranking, and station-level charts.

## Development

```bash
npm install
npm run dev
```

## Quality Checks

```bash
npm test
npm run lint
npm run build
```

## Deployment

The Vite base path is configured for GitHub Pages at `/typhoon-replay-dashboard/`.

```bash
npm run deploy
```
